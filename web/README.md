# Ground Up web

Next.js 16, React, Tailwind CSS, Motion and Geist. From this directory, run `npm ci` and `npm run dev` with the local API running and seeded. The default API URL is http://localhost:8001. Use `.env.example` for configuration.

See [Setup](../docs/SETUP.md) for the production build and Playwright commands and the [Demo guide](../docs/DEMO_GUIDE.md) for seeded accounts.
