# Implementation plan

1. Complete the matcher and age policy. Generate deterministic athlete, opportunity, organisation, post and relevance data and seed it safely.
2. Run the shared-pool evaluation with baseline comparisons, age-policy-preserving ablations, confidence intervals and sensitivity analysis.
3. Migrate PostgreSQL and complete demo authentication, role enforcement and the application and organisation workflows.
4. Connect the existing frontend to the API and add the evaluation and organisation dashboards.
5. Verify the complete demo on desktop and mobile, capture screenshots and publish setup, methodology, final report and viva material.

All five stages were executed for the local demonstration. The [traceability matrix](REQUIREMENTS_TRACEABILITY.md) records remaining research and hosted scope. The [test report](TEST_REPORT.md) links the browser evidence and verification commands.
